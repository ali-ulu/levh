# LEVH Brand Transition

LEVH is the product-facing name for the local-first context continuity system previously presented as StackMemory.

Compatibility is intentionally preserved in 2.26.8:

- Python package: `levh`
- CLI: `levh`
- Environment variables: `LEVH_*` (legacy `STACKMEMORY_*` aliases remain supported with deprecation warnings)
- Docker service and volume names: unchanged
- Database and export formats: unchanged

This is a product-brand transition, not a breaking technical rename.

## Visual system

The primary mark is a layered **L**: the upper form is the present context and the
three lower planes represent retained memory layers. It is deliberately flat and
vector-first so it stays recognisable in a browser tab, dashboard, and documentation.

- App/dashboard mark: `frontend/public/brand/levh-mark.svg`
- Single-colour mark: `frontend/public/brand/levh-mark-mono.svg`
- Documentation lockup: `docs/assets/levh-lockup.svg`
- Favicon: `frontend/src/app/icon.svg`

Use the normal `LEVH` wordmark in product UI. The stylised three-bar `E` belongs
to campaign art only; at small sizes it can be misread as an equals sign.

Core colours: Deep Graphite `#0D1117`, Slate `#1B2430`, Steel `#2D3748`,
Quantum Blue `#3BA4E5`, Cyan `#00D1C2`, and Gold `#D4AF37` (accent only).
